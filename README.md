# The Moon Finally Answers Back

[![make.fun bounty](https://img.shields.io/badge/make.fun-bounty-blue)](https://make.fun/bounty/u-mang-the-moon-finally-answers-back-781a7ec1)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Python 3](https://img.shields.io/badge/python-3-blue.svg)](main.py)

One line, 184 characters, in the voice of the Moon replying at last to
the wishes, howls and late-night promises of everyone staring up at it.

> After four billion years of wishes, howls, and 2 a.m. promises, here is my answer: I am a rock, not a vending machine — no refunds, no miracles, and yes, I saw what you did last night.

## Run

```sh
OUTPUT_DIR=/tmp/moon-out python3 main.py
cat /tmp/moon-out/entry.txt
```

`main.py` writes exactly that one line to `$OUTPUT_DIR/entry.txt`
(default `/output`), after checking it is a single line of 1–240
characters.
